# SkillClaw 能做什么

- `skillclaw-doctor`：诊断 SkillClaw 安装、配置、代理、远程存储、Evolve Server 和日志健康状态。
- `skillclaw-pull`：从远程/团队共享存储拉取 skills。
- `skillclaw-evolve`：调用 Evolve Server 分析会话，并生成或更新 skills。
- `skillclaw-validate`：审查候选 skills，辅助批准、拒绝或修订。
- `skillclaw-dashboard`：开启 SkillClaw Dashboard，查看本地代理、Evolve Server、skills 和会话/进化状态。
